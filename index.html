📥 17.live ギフト履歴 Excel エクスポート

17.live にログイン中のアカウントの受信ギフト履歴を全件取得し、
集計付きの Excel ファイル(.xlsx)としてダウンロードする Bookmarklet です。

✨ 4つのシート(サマリ / 贈り主ランキング / ギフトランキング / 全履歴)を含む Excel を自動生成します。

📌 インストール方法

下のオレンジボタンを ブックマークバーにドラッグ してください。

📥 17.live Gift Export

使い方

1. 17.live にログインした状態で任意のページを開く
2. ブックマークバーの「17.live Gift Export」をクリック
3. 自動で全件取得 → Excel ファイルがダウンロードされる
iOS Safari では Bookmarklet を直接ドラッグできないため、少し手順が必要です。

インストール手順

1. 下のボタンでコードをコピー
2. Safari 下部の 共有 → ブックマークを追加 をタップ(タイトルは「Gift Export」など)
3. Safari 下部の📖アイコン → 右下の 編集 をタップ
4. 追加したブックマークをタップ → URL 欄をすべて削除
5. URL 欄に コピーしたコードを貼り付け → 完了

使い方

1. Safari で 17.live にログイン
2. 📖 → ブックマークから「Gift Export」をタップ
3. Files アプリの「ダウンロード」に xlsx ファイルが保存される
⚠️ Files アプリ → ダウンロードフォルダから Numbers / Excel で開けます。
Android Chrome ではブックマークバーから直接タップで起動できないため、アドレスバー経由で呼び出します。

インストール手順

1. 下のボタンでコードをコピー
2. このページを ☆ でブックマーク登録
3. Chrome のメニュー → ブックマーク → 追加したものを編集
4. 名前を「Gift Export」に、URL欄をすべて消してコピーしたコードを貼り付け

使い方

1. 17.live にログイン
2. アドレスバーに gift export と入力
3. 候補に出てくる「Gift Export」をタップ

🛡️ 仕様・注意事項

  
    
    
  • 17.live にログイン中のアカウントの履歴を取得します
    • 
    
  • 取得した認証情報は外部に送信されません(すべてブラウザ内で完結)
    • 
    
  • 処理中はページを閉じないでください
    • 
    
  • 件数が多いと数十秒〜数分かかる場合があります
    • 
    
  • Excel ライブラリ(SheetJS)を CDN から読み込みます
    •

    • 
    
  • ギフトランキング:ギフト種類別の集計
    •
